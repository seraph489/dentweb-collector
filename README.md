# 덴트웹 Windows 수집기

**최신 0.2.0은 Python이 포함된 독립 실행판입니다. Python이나 가상환경을 별도로 설치하지 않아도 됩니다.**

[Windows 64비트 실행판 다운로드](https://github.com/seraph489/dentweb-collector/releases/download/v0.2.0/DentwebCollector-Windows-x64-0.2.0.zip) · [최신 릴리스](https://github.com/seraph489/dentweb-collector/releases/latest)

## 사용 방법

1. ZIP **전체**를 원하는 폴더에 압축 해제합니다.
2. `환경점검.cmd`를 실행합니다. 덴트웹 입력 없이 내장 실행 환경을 점검합니다.
3. `최초설정.cmd`를 실행해 이 PC의 덴트웹과 보관 폴더를 연결합니다.
4. 덴트웹에 로그인하고 **경영/통계** 화면을 열어 둡니다.
5. `DentwebCollector.exe`를 실행하고 대상월을 `YYYY-MM` 형식으로 입력합니다.

**EXE만 따로 복사하면 안 됩니다.** `_internal` 폴더에 Python과 필수 라이브러리가 들어 있습니다. 폴더 전체를 함께 보관·전달하세요.

덴트웹이 관리자 권한으로 실행 중이면 수집기도 우클릭 → **관리자 권한으로 실행**합니다. 프로그램 자체가 권한을 올리거나 Windows 보안 설정을 변경하지 않습니다.

## 최초 설정과 기존 운영 이관

- **처음 사용하는 새 운영:** 이전 수집 이력이 없을 때만 빈 로컬 보관 폴더, 이 PC의 `DentWeb.exe`, 실제 공용 `00_INBOX`를 선택하고 표준 화면 확인 항목을 체크합니다.
- **기존 병원 PC를 옮기는 경우:** 기존 운영 설정 연결을 사용합니다. 원본·해시·접수/재개 이력과 경로를 별도로 비공개 이관·확인하세요. 새 빈 이력으로 기존 수집을 다시 시작하지 않습니다.
- 프로그램과 운영 데이터 폴더는 분리합니다. 업데이트할 때 기존 원본과 운영 이력을 유지합니다.

공유 ZIP에는 실제 병원 설정, 환자 엑셀, 수집 이력, 개발 가상환경이 들어 있지 않습니다. 경로 설정은 받는 PC에서 최초 한 번 필요합니다.

## 수집하는 자료

| 자료 | 조건 및 용도 |
|---|---|
| 기간별 수입 통계 | 대상월 1일~말일. 수입 항목별 합계·VAT 교차검증 |
| 수납일 기준 수납통계 | 수납일 기준·특정기간·수납/보험 전체 필터. 취소·환불 음수행 보존 |
| 연간 보험청구액 | 해당 연도 누적 원본. 실제 지급액·통장입금 자료가 아님 |

수입·수납 날짜는 확인된 달력 날짜 셀을 자동 선택합니다. 화면 배율을 반영한 좌표 및 실제 조회 값·저장 창 기간을 확인합니다. 파일 안정화·크기·형식·SHA-256·사본 무결성을 확인하고 기존 파일을 덮어쓰지 않습니다.

보험청구액 사본에는 대상월·실행번호를 붙입니다. 같은 연도 누적본끼리 더하지 않고 최신 생성본을 비교하며, 대상월이 지난 뒤 생성된 파일만 월말 이후 최종 후보입니다. 세 자료를 서로 더해 매출을 만들지 않습니다. 파일 내부 기간·금액 대사와 회계 반영은 별도 Mac 처리기의 검증 범위입니다.

## 검증 범위

- 자동 테스트 **118개 통과**.
- 내장 Python·UIA/Win32/COM 라이브러리·설정 화면 초기화·보조 작업 실행 점검 통과.
- Python 경로와 기존 임시 캐시를 제외하고, 한글·공백이 있는 별도 경로로 ZIP을 풀어 독립 EXE 자체 점검 통과.
- 기존 날짜 자동화는 개발 PC에서 실제 날짜와 저장 창 기간까지 검증했습니다.
- **이번 EXE로 다른 실제 병원 PC에서 수집한 결과는 아직 미검증**입니다. 해당 PC의 덴트웹 버전·권한·화면 배율은 그 PC에서 확인해야 합니다.
- 로그인 만료·화면 잠금·절전·원격 연결 종료 상태의 실제 수집은 미검증입니다.

프로그램은 ChatGPT/Codex, 원격 브라우저 또는 모델 호출에 의존하지 않습니다. 환자·진료·수납·예약 수정, DB 쓰기, Notion 쓰기를 수행하지 않습니다.

## 이전 버전에서 환경 오류가 난 경우

0.1.2는 별도 Python 가상환경이 필요한 코드 배포본이었습니다. `Python environment is not configured`는 시스템에 Python이 있어도 필요한 `.venv` 경로가 없으면 발생합니다. **외부 공유에는 위의 0.2.0 독립 실행판을 사용하세요.** 이전 릴리스는 이력 보존용입니다.

ZIP과 함께 릴리스에 제공된 `SHA256SUMS.txt`, `RELEASE_VALIDATION.json`으로 파일 무결성과 검증 범위를 확인할 수 있습니다.
